- 用户要求**真的把视频看完再说**（“你必须看完抖音视频再说”）。只看标题、简介或别人的描述不算。回复里要写清楚是怎么看的（下载全片、转写全部口播、按镜头逐个过），并给出带时间点的内容作为证据。
- 分工：用户真人出镜（全屏口播和录屏小窗），Kiro 负责剪辑用的画面：白底动画、聊天气泡、图片片段、旧版本截图、字幕。

## 怎么“看完”一条抖音视频

1. **短链接 → 视频编号：** `curl -sIL https://v.douyin.com/xxxx/`，302 跳到 `iesdouyin.com/share/video/{编号}/`。
2. **下载：** yt-dlp 抖音需要新鲜 cookie，直接用会失败。改用 Playwright 打开 `https://www.douyin.com/video/{编号}`，监听 `aweme/v1/web/aweme/detail` 的响应，取 `aweme_detail.video.bit_rate[]`：选 `gear_name` 为 `normal_1080_0`、`format` 为 `mp4` 的那条，它的 `play_addr.url_list[0]` 是带声音的完整 mp4。用 curl 下载时带 `-e https://www.douyin.com/`。同一个响应里还有 `statistics`（点赞、收藏、分享、评论数）和 `chapter_list`（抖音自动分的章节和时间点）。
3. **转写口播：** faster-whisper `large-v3-turbo`，`compute_type=int8`，8 核 CPU，11 分半的音频约 4 分钟转完。`initial_prompt` 里写上可能出现的专有名词。即使这样，专有名词仍会识别错（“3.js”“godon”“Triple”“谷歌绑定”），引用前对照画面改正。
4. **看画面：** ffmpeg `fps=1/3,scale=480:270,drawtext=时间,tile=4x4` 每 3 秒一帧，16 帧拼一张，11 分半共 15 张，逐张用 `read_file` 看。
5. **逐个镜头过：** ffmpeg `select='gt(scene,0.22)',showinfo` 取出每次画面切换的时间，每个镜头截首帧拼成总览图再看一遍，并统计每段平均镜头长度。游戏里飘落的花瓣、粒子会被误判成切换，要看图剔除。
6. **版权：** 参考视频、它的转写全文和截图帧都是别人的作品，只在会话里分析，不上传公开仓库。脚本里只写自己的拆解和转述。截图里出现的别人账号名不写。

## 参考视频拆出来的教程结构（AI充电官，11 分 35 秒）

完整拆解见 `files/2026-11-05-tutorial-video/教程视频脚本.md` 第一节。可以复用的要点：

- 冷开场 12 秒只放成品，1.5 秒一个镜头；然后开场说清楚“这期讲什么”，用一张路线图预告几个步骤。
- 每一步开头一张章节卡（“• 第一步”+ 超大标题 + 红色短横线 + 底部进度短线），每一步只讲一个工具、一个结论。
- 中间安排一次翻车（第一版人物“毫无关联”），接一句“先别着急走”留人，再给办法。
- 抽象的东西做成白底动画：对比表、决策树、步骤条、循环图。
- 真人只在左下角圆角小窗里；录屏斜放在灰底上，讲到哪里放大到哪里。
- 结尾一张工作流总结条，方便截图收藏。
- 口播约 2840 字，每秒 4.2 字（含停顿）。用这个语速估算脚本时长。
- 它的弱点：3 分钟游戏演示口播很少；字幕没校对。

## 用网页代码做动画素材

参考视频的白底动画可以用 HTML/CSS 做，再逐帧截图合成视频：

1. 页面固定 1920×1080，动画全用 CSS `@keyframes`。页面里放一个跳帧函数：
   `window.seek = ms => document.getAnimations().forEach(a => { a.pause(); a.currentTime = ms; });`
2. 中文字体：下载 Noto Sans SC（`https://github.com/google/fonts/raw/main/ofl/notosanssc/NotoSansSC%5Bwght%5D.ttf`，17 MB，OFL 许可）放到页面同一个文件夹，`@font-face` 引用。
3. Playwright 用假域名拦截读本地文件（做法见 `kiro-sandbox-notes.md`），`setViewportSize(1920, 1080)`，等 `document.fonts.ready`，然后循环 `seek(i * 1000 / 30)` + `page.screenshot`。截图写到 `/projects/sandbox/.kiro/artifacts/screenshots/` 下。75 帧约 4 秒。
4. ffmpeg `-framerate 30 -i f%03d.png -c:v libx264 -pix_fmt yuv420p -crf 18` 合成 mp4。抽几帧拼图检查。
5. 样片：`files/2026-11-05-tutorial-video/sample-chapter.mp4`，源文件 `chapter.html`。颜色：底 #F6F5F1、字 #111111、强调 #E8542F。
