# 用代码做 Three.js 场景：工作流和踩过的坑

来自 2026-11-04 雨夜城市场景（`files/2026-11-04-rainy-city/`）。以后做类似的 3D 场景，先读这份。

## 工作流

1. **查当前版本和 API。** AI 容易写出旧版写法。先 `npm view three version`，锁定版本，看 release notes 和迁移指南。
   - 2026-11 时最新是 r187。r183 起 `PostProcessing` 改名 `RenderPipeline`，`Clock` 弃用改用 `Timer`；r186 删了 `PCFSoftShadowMap`。
2. **拆解参考图。** 把画面拆成几个部分（主体、地面、天气、氛围），每部分对应一种具体技术，再开始写代码。只说“要好看”没用。
3. **定方案和验证方式。** 先想好怎么截图验证，再选渲染器。
4. **按效果拆模块写，打包成一个文件。** esbuild 打包成 IIFE 格式的 `app.js`，`<script src>` 普通引入。打包后的文件也提交，静态托管可以直接用。
5. **加调试截图开关。** 例如 `__rainy.shot({ t, yaw, pitch, flash })`：用固定时间和视角渲染一帧后停住。软件渲染很慢，没有这个开关就截不了图，也没法前后对比。
6. **截图迭代，每轮只解决几个明显问题。** 每轮至少看：正面、转一个角度、特殊状态（比如闪电）、手机竖屏。同时检查控制台有没有报错。
7. **尽早让用户在真机上看。** 软件渲染和真显卡的计算行为不同（见下面的 NaN 问题）。第一版出来就给可以直接打开的链接。
8. **用户反馈的 bug：先复现原理，再修，再验证。** 例如故意放一个坏像素，复现整屏变黑。

## 场景技术清单（雨夜城市用到的）

| 效果 | 做法 |
| --- | --- |
| 大量建筑 | 单位立方体 `InstancedMesh`，一次绘制。窗户在片元着色器里按楼的实际尺寸算（`instanceMatrix` 每列的长度就是尺寸）。远处窗格小于一两个像素时换成块平均亮度，避免摩尔纹 |
| 杆件结构（塔、塔吊、栏杆） | 用“两端点 + 粗细”描述每根杆，合成一个实例网格 |
| 湿地面 | `Reflector` 渲染镜像图，按噪声分积水和湿水泥：积水清晰反射，湿水泥用 mip 偏移模糊并沿竖直方向多次采样拉长；叠加涟漪法线和菲涅尔 |
| 雨 | `LineSegments`，下落和循环在顶点着色器里算；亮度按到灯的距离算。倒影相机关掉雨的图层 |
| 蒸汽 / 烟雾 | 朝向镜头的实例面片，采样预先生成的可平铺噪声图（比每像素算 fbm 便宜） |
| 后期 | 坏像素清零 → 泛光 → 线性空间调色 → `OutputPass`（色调映射）→ 显示空间的颗粒和暗角 |
| 声音 | Web Audio 滤波噪声合成，必须由用户点击触发 |
| 画质 | 按设备分档；运行几秒后如果平均帧率低于阈值，自动降低像素比 |

## 踩过的坑

### 窗户里出现杂色噪点
- 现象：部分窗户里是彩色的电视雪花点。
- 原因：每个实例都相同的参数（随机种子）通过普通 varying 传到片元着色器，插值后有极小的误差；哈希函数把误差放大，按像素得到不同的随机结果。
- 修复：用 `flat varying` 传实例常量，种子再量化一次（`floor(x * 997.0 + 0.5) / 997.0`）。

### 真显卡上画面闪烁、大块变黑（软件渲染看不出来）
- 现象：Mac Chrome 上只有画面顶部一条正常，其余是黑的，并且一闪一闪。
- 原因：某些像素算出 NaN。泛光会做多级大范围模糊，一个 NaN 像素会扩散成整块黑色。
- 来源：开 MSAA 时，像素中心可能落在三角形外，插值出的值会超出顶点值的范围（比如略小于 0）；`pow(负数, y)` 在真显卡上是 NaN。
- 修复：
  1. 所有 `pow` 的底数先 `clamp` 到合法范围。
  2. 在泛光之前加一个清理 pass：`(floatBitsToUint(x) & 0x7f800000u) == 0x7f800000u` 判断 NaN / 无穷大并清零，再限制最大亮度。用位运算是为了防止编译器的快速数学优化把 `isnan` 判断去掉。
- 验证方法：临时放一个输出 `uZero / uZero` 的小方块（用 uniform 防止编译期常量折叠），对比有无清理 pass。

### 构图像一堵墙
- 现象：近处的楼太高、太近，看不到天空，窗户显得很大。
- 修复：近处一排楼往后推；高度上限随距离增加（`h = min(h, 40 + 距离 * 0.34)`）；超高的楼只放在远处；加大指数雾，让远处的楼融进天空。

### 其他
- 无头浏览器里没有中文字体，界面上的中文会显示成方框。截图前隐藏界面文字，不代表真机有问题。
- `ShaderMaterial` 要支持雾：`fog: true`，uniforms 里合并 `UniformsLib.fog`，着色器里 include `fog_pars_*` 和 `fog_*`，顶点着色器里的变量必须叫 `mvPosition`。
- 多个材质共用同一个 uniform 对象，改一处全场景生效。`Reflector` 会克隆传入的 uniforms，创建后要把需要共享的 uniform 重新赋值回去。
- 倒影相机是在第一次调用 `getReflectionCamera(camera)` 时从主相机克隆的，图层要在那之后再单独设置。
