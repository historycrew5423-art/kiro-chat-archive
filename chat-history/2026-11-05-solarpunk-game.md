### Kiro 做了什么

**角色模型**
- tmpfiles 的链接是一个下载页，真正的文件在页面里的 `/dl/<时间戳>.<签名>/...` 链接上，用这个链接加上 Referer 才下到 5.3 MB 的 GLB。页面写着文件 48 小时后过期，所以先存进了仓库。
- 分析模型：Tripo 生成，一整块静态网格（约 1 万个三角面），没有骨骼和动画，高 0.98，面朝 +Z。渲染四个角度看：黄色袋鼠脑袋，穿红黑条纹的火枪手衣服、披风、靴子，腰上挂着剑。
- 贴图从 5.3 MB 压缩到 1.2 MB（金属度/粗糙度那张 PNG 改成 JPEG，法线和粗糙度贴图缩到 1024）。

**找免费素材（Poly Haven，全部 CC0）**
- 天空：看了 10 张天空 HDRI 的缩略图，选 `kloofendal_48d_partly_cloudy_puresky`（深蓝天 + 白色积云，最像参考图）。下载 8K 色调映射过的 JPG，裁掉地平线以下，做成 8192×2230 的背景图和一张小的环境光图。照片里太阳的方位正好在镜头右后方，和参考图的光一致。
- 树叶：Poly Haven 的树模型都是几百万面，不能直接用。改用 `island_tree_02` 的叶片贴图，用 Pillow 自动切出 8 片叶子，拼成两种叶簇贴图，再用代码长出整棵树。
- 岩石和草地：`mossy_rock`、`leafy_grass` 的 1K 贴图。

**拆解参考图、定布局**（写在 `files/2026-11-05-solarpunk-game/DESIGN.md`）
- 固定一个“参考镜头”，按每个建筑在参考图里的像素位置和估计距离反推世界坐标（`src/layout.js` 的 `refPos()`）。

**搭场景和游戏**（`files/2026-11-05-solarpunk-game/`）
- 城市 2 万多栋楼（一个实例网格）、两座花园塔、玻璃巨塔和圆环、高架绿廊和电车、山顶公园、金色飞行器。
- 主角：按身体部位自动算蒙皮权重，绑 11 根骨头，用代码做蹦跳动画。
- 玩法：收集 10 颗阳光种子 → 电梯启动 → 坐电梯上空中花园。

**截图迭代 5 轮（参考镜头）**
1. 第 1 版：镜头太低，平视着城市；整体发白、没有明暗；白塔上有噪点；玻璃巨塔几乎看不见。
2. 把山抬高到 300 米、镜头 362 米；阳光加强、环境光减弱；修掉噪点（窗带随机数里混进了逐像素变化的值）；玻璃调深。
3. 左下角岩丘是一团光滑的绿球 → 改成单独雕刻的岩石；平台上的绿植从零散小球改成浓密树冠；城市留出公园空地；山脚一公里内只放低楼。
4. 框景的近景树叶是黑色剪影（被大树冠挡住了阳光）→ 框景树叶单独一组，不接收阴影。
5. 换成 three r186 新增的 `SunLight`（两级级联阴影），城市里的楼开始互相投影，画面有了参考图那种明暗。

**功能测试（无头浏览器）**
- 点开始 → 镜头从参考构图飞到主角身后 → 按 W 能走、空格能跳、HUD 正常。
- 把主角依次放到 10 颗种子的位置，10 颗都能捡到，提示“电梯已经启动”；走进电梯后开始上升。软件渲染太慢，电梯没等到顶。

游戏已经存在 GitHub 上了，源码、素材和打包好的文件都在。我刚模拟你队友的操作验证了一遍：只下载游戏文件夹，装依赖、重新打包，打包出来的文件和仓库里的一模一样。他拿到就能改，也能重新构建。

**游戏在这里：** [files/2026-11-05-solarpunk-game](https://github.com/historycrew5423-art/kiro-chat-archive/tree/main/files/2026-11-05-solarpunk-game)，约 6 MB。

**让你队友这样下载（只下游戏，不下整个仓库）：**
```bash
git clone --filter=blob:none --sparse https://github.com/historycrew5423-art/kiro-chat-archive.git
cd kiro-chat-archive
git sparse-checkout set files/2026-11-05-solarpunk-game
cd files/2026-11-05-solarpunk-game
npm install
npm run build
node serve.mjs   # 然后打开 http://localhost:8765
```
需要装 Node.js 18 或更新的版本。不能直接双击 `index.html` 打开，浏览器会拦住贴图和模型的加载。
