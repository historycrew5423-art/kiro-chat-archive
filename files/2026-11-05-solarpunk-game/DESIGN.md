# 太阳朋克世界：参考图拆解和游戏设计

## 参考图里有什么（按画面位置，画面宽 1024、高 573）

**镜头**：站在城外一座山崖上，几乎水平地望向城市，略微仰一点（地平线在画面中线偏下）。
城市在脚下几百米处铺开，一直延伸到天边。左下角是长满苔藓的岩壁和一棵树，右上角和右下角有近处的树叶，形成画框。

**光**：下午偏晚的暖色阳光，从镜头右后方照过来。所有建筑右侧和正面被照亮，左侧在阴影里。
天空上蓝下浅，地平线附近有一层发白的空气透视；左边和右边各有一大团积云。

**主体建筑（从近到远）**

| 位置 | 建筑 | 特征 |
| --- | --- | --- |
| 右侧，最近 | 空中花园塔 | 白色圆柱模块 + 铜橙色环带；中段一个巨大的圆盘平台，上面是茂密的森林，藤蔓从平台边缘垂下；平台下方是白色机械结构和橙色面板；塔顶伸出画面 |
| 右下 → 中远 | 高架绿廊 | 从右下角斜着伸向城市中心的宽桥面，中间两条轨道，两侧是绿色种植槽；经过空中花园塔下方时有一个连接站 |
| 左中 | 第二座花园塔 | 细高白塔，中间一个较小的圆盘，盘上一团绿植，下面是带橙色点缀的支撑柱 |
| 正中，最远 | 玻璃巨塔 + 圆环门 | 蓝色玻璃的超高塔楼，伸出画面顶部；塔脚有一个巨大的白色圆环，正对着一条笔直的林荫大道 |
| 下半部 | 城市 | 密集的白色/浅灰高楼，楼间有很多树；右侧（高架以东）是森林，房子稀疏；最右边地平线是海湾 |
| 左上 | 金色飞行器 | 像鸟一样的金色有翼飞船；远处还有几个小飞行物 |

**配色**：白/奶油色建筑、深绿植被、铜橙色点缀、蓝天白云、暖阳。

## 搭建方案

| 部分 | 做法 | 素材 |
| --- | --- | --- |
| 天空和云 | 真实照片天空（不再用代码画云） | Poly Haven `kloofendal_48d_partly_cloudy_puresky`，CC0 |
| 环境光 | 同一张天空图缩小后生成 | 同上 |
| 树叶 | 用照片叶子拼出叶簇贴图，再用代码长出整棵树 | Poly Haven `island_tree_02` 的叶片贴图，CC0 |
| 主角 | 用户提供的模型；没有骨骼，代码里自动绑一套简单骨骼做跳跃动画 | 用户提供（Tripo 生成） |
| 建筑、高架、圆环、飞行器、岩石 | 代码生成 | — |

所有建筑位置都按参考图反推：先固定一个“参考镜头”，再按每个建筑在参考图里的像素位置和估计距离算出世界坐标（`src/layout.js`）。
游戏开场就是这个镜头，然后镜头飞到主角身后。

## 游戏

- 主角是一只穿火枪手服装的袋鼠，在山顶公园出发。
- 目标：沿着高架绿廊走到空中花园塔，沿路收集 **10 颗阳光种子**。集齐后连接站的电梯启动，坐电梯上到空中花园就算通关。
- 操作：WASD / 方向键移动，Shift 跑（跳得更远），空格跳，按住鼠标拖动转镜头，滚轮拉近拉远。
- 袋鼠走路是一蹦一跳的。
