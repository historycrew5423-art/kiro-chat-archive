## 1. 这是一个什么游戏

2079 年，AI 包办了所有工作，人类不用再上班，都躺在“体验舱”里，用脑机接口随机体验过去的人生。玩家扮演奶龙，每一局体验一段人生：开着星际战机飞向地球，落进一段段真实的历史，用那个年代的梗打怪、割草、打 Boss，把灰色的世界染回彩色。死了就“人生重开”，换一段人生再来。

**三个支柱**

| 支柱 | 在游戏里是什么 |
| --- | --- |
| 肉鸽 | 每局随机：走哪条路线、遇到什么敌人、能拿到哪些升级都不一样。玩家边打边升级，每次从 3 张梗卡里选 1 张，一局里慢慢攒出自己的打法（构筑）。死了这一局就结束，局外只保留少量成长 |
| 梗 | 梗就是武器、技能和升级。每张梗卡是一个网络梗，效果和这个梗的意思挂钩，例如“躺着拯救世界”是站着不动时变强。敌人、Boss 和台词也来自梗 |
| 历史 | 每一章是一段真实的历史：一个年份、一个地方、当年的大事。这一章能抽到的梗卡来自那个年代 |

**玩家应该感受到的**

1. 割草的爽：成群的弱小敌人，一下清掉一片。
2. 每局不一样：同样的开局，拿到不同的梗卡，打法完全不同；两张特定的梗卡凑齐还能合体。
3. 认出梗的笑：每个梗都有画面和声音。不认识这个梗的人，看卡上的一句出处也能懂。
4. 笑完的安静：每章打完，切到一段安静的回忆，再回到 2079 年。

**参考作品**

| 作品 | 借什么 |
| --- | --- |
| 《哈迪斯》（Hades） | 一个房间一个房间地打；出口的门上标着奖励类型；两种祝福凑齐会出现更强的组合祝福（本作的“合体”） |
| 《吸血鬼幸存者》（Vampire Survivors） | 成群的敌人；打怪攒经验，升级时三选一 |
| 《雨中冒险 2》（Risk of Rain 2） | 3D 第三人称的肉鸽，升级效果可以叠加 |
| 《人生重开模拟器》（2021 年爆红的中文网页游戏） | 开局抽天赋、随机过一生、结束时给一段人生总结。“人生重开”这个说法就是它带火的 |
| de Blob | 把被抽干颜色的城市重新涂回彩色 |

## 2. 术语表

| 词 | 意思 |
| --- | --- |
| 肉鸽 | roguelike / roguelite 的中文俗称。一局一局地玩，每局随机，死了从头开始，局与局之间保留少量成长 |
| 割草 | 中文游戏俗语，指成片地清掉大量弱小的敌人 |
| 一局 | 从开始体验一段人生，到死亡或通关。英文 run |
| 构筑 | 一局里拿到的梗卡组合，决定这一局怎么打。英文 build |
| 梗 | 网络流行语、表情包、名场面 |
| 梗卡 | 本游戏的升级卡。每张卡是一个梗，给奶龙一个能力或者改造一种攻击 |
| 叠加 | 同一张梗卡再拿一次，效果变强，最多 3 层 |
| 合体 | 同时拥有两张特定的梗卡时，可以抽到一张更强的合体卡 |
| 抽象 | 中文网络用语，指荒诞、无厘头、出人意料的幽默风格。不是指抽象画 |
| 鬼畜 | 把声音和画面切碎、重复、卡在节拍上的恶搞剪辑风格 |
| 奶龙 | 中文网络上流行的卡通形象：一只黄色、圆滚滚的小龙，表情夸张，表情包很多。它有著作权方，见第 16 节 |
| 体验舱 | 2079 年人们躺进去体验人生的设备，也是游戏的大厅 |
| 章 | 一段历史，例如“2020 年春天”。一章由几个区域和一个 Boss 组成 |
| 区域 | 一章里的一块战斗场地。清完才能去下一个区域 |
| 灰色 / 彩色 | 世界和人的颜色。灰色表示没有生气，彩色表示有生气。不表示生病 |
| 灰色路人 / 彩色路人 | 场景里的普通人。灰色路人不是敌人；被奶龙唤醒后变成彩色路人，成为队友 |
| 唤醒 | 用口罩打中灰色路人，让他变回彩色 |
| 包住 | 敌人被打败时的样子：被一个口罩包起来，不会死，也没有血腥画面 |
| 口罩包 | 敌人被包住后变成的白色小包，会飘上天，越积越多 |
| 抽象版 / 回忆版 | 同一个地方的两种呈现：抽象版热闹、搞笑，用于战斗；回忆版安静、真实，用于每章结尾 |
| 3D 事故 | 3D 游戏里常见的出错画面，例如 T-pose（模型没加载出动作时张开双臂站着的默认姿势）、穿模（两个模型互相穿过去）、贴图丢失。本作故意把它们做成笑点 |
| 人生重开 | 死亡后重新开一局 |
| 记忆碎片 | 局外货币，死了也保留，用来解锁新内容 |

## 3. 世界观

- 2079 年，AI 发展到了巅峰。人类再也不用在现实世界里工作，大家躺进体验舱，接上脑机接口，随机体验世界上不同的人生。
- 同样是 18 岁，可以出生在江西的一座小城，也可以出生在上海：吃的不一样，爸妈的教法不一样，看问题的方式不一样，遇到的时代大事也不一样。
- 【暂定】人人都是奶龙：体验舱生成人生时会读父母的期望。所有父母都望子成龙，AI 算力不够，生成到一半降了级，于是每个人都成了奶龙。口号：“望子成龙，结果都成了奶龙。”
- 【暂定】体验舱里的过去一开始是灰的，因为这段人生还没被真正活过。玩家用那个年代的梗，把它一点点染回彩色。
- 【暂定】2079 年的现实也是灰的：人人躺着，没有生气。每通过一章，2079 年的城市就多一处被点亮的地方。

**“回到未来”在游戏里的三层意思**

1. 结构：从 2079 年回到过去，打完再回到 2079 年。
2. 玩法：在过去做的事会改变未来。每通过一章，2079 年的城市会多出那一章留下的东西。MVP 里，打完 2020 年这一章，山上的工地会长成 2079 年的未来医院。
3. 情绪：2079 年的人什么都不缺，最想回去体验的，是当年大家咬着牙过来的日子。

## 4. 一局怎么玩

### 4.1 完整版的一局

1. 在 2079 年的体验舱大厅里开始。
2. 投胎：抽 3 张人生卡，选 1 张。人生卡上写着出生年份、出生地、家庭和职业（第 11.1 节）。
3. 开星际战机飞向地球，在地球上选下一章去哪（一个地点加一个年份）。
4. 打一章：区域 → 选门 → 区域 → …… → Boss。边打边升级三选一。
5. 看这一章的回忆片段。
6. 回到太空，选下一章。一局 3 到 5 章，对应人生的几个阶段。
7. 最后一章打完，回到 2079 年，看这一生改变了什么。
8. 任何时候生命归零：显示人生总结，然后人生重开。

### 4.2 MVP 的一局

只有一章：2020 年春天（第 8.3 节）。

1. 标题画面：2079 年的体验舱。
2. 人生卡：固定为“2020 年春天 · 医生”。旁边几张卡是锁着的，提示以后还有别的人生。
3. 开场：星际战机从太空飞向地球。地球上只有“2020 · 春”一个点亮着，其他点显示问号。选中以后，战机俯冲，穿过云层，落进一座灰色的城市。整段约 20 秒，按任意键跳过。
4. 区域 1（教学）→ 选门 → 区域 2 → 选门 → 区域 3 → 区域 4 → Boss。
5. 打完 Boss：回忆片段 → 回到 2079 年（工地长成未来医院）→ 人生总结。
6. 中途死亡：人生总结 → 人生重开。换一个随机种子，从区域 1 重新开始，梗卡清空。

时长：一局 6 到 8 分钟。演示用的短局（网址加 `?demo=1`）只有区域 1、区域 4 和 Boss，约 3 到 4 分钟：区域 1 打完，日历直接翻到第 6 天，工地进度和天气跟着跳过去；区域 4 的敌人生命按第 2 个区域算（×1.25）。演示限时【待定】。

### 4.3 区域、门和清场条件

- 区域之间用施工围挡隔开。清完一个区域，围挡打开。
- 有的区域打完会出现两扇门，通向两个不同的区域（路线见第 8.3 节）。每扇门上有一个图标，表示走这扇门的话，下一个区域打完时的奖励偏向哪一类梗卡：攻击、防御或召唤。图标每局随机。
- 清场条件有三种：
  - 清怪：分 3 波刷怪。一波的敌人（包括中病毒分裂出来的小病毒）打掉 80%，就刷下一波。第 3 波刷完以后，场上剩下的敌人少于 5 个时，区域结束，剩下的敌人自动被包住。
  - 守护：坚持 60 秒，保护场上的目标。时间到了，区域结束，剩下的敌人自动被包住。
  - 精英：打败精英敌人后，区域结束，剩下的敌人自动被包住。

### 4.4 升级

- 打败敌人得经验：小病毒 1，中病毒和喷嚏病毒 3，大病毒 10，精英 30。唤醒一个路人得 2。
- 哪些情况给奖励：
  - 被大招包住的敌人，和正常打败一样，给经验、大招条和分数。
  - 区域结束时自动被包住的敌人，只飘上天、算进“送走病毒”的数量，不给经验、大招条和分数。
  - 同一个路人变灰以后再唤醒，照样给经验和大招条；分数和记忆碎片只在第一次唤醒时给。
- 经验条满了就升一级：游戏暂停，弹出 3 张梗卡，选 1 张。从第 n 级升到第 n+1 级需要 10 + 8 × n 点经验。
- 每清完一个区域，额外给一次三选一，3 张里至少 2 张属于来时那扇门上的那一类。区域 1 和区域 4 前面没有门：区域 1 的奖励不偏向任何一类；区域 4 的奖励由守护的结果决定（第 8.3 节）。
- 每清完一个区域，回复 20% 生命。
- 按第 8.3 节的刷怪量，一局大约能选 10 到 14 次。

## 5. 战斗

### 5.1 操作

| 按键 | 动作 |
| --- | --- |
| W A S D | 移动 |
| 鼠标 | 转镜头。屏幕中间是准星。第一次点击画面时锁定鼠标 |
| 左键（按住连发） | 扔口罩（主攻击） |
| 右键（按住至少 0.4 秒再松开） | 扔 N95（技能）。不到 0.4 秒松开不会扔出 |
| Q | 放大招「奶-蛙之波」 |
| Shift | 冲刺，冲刺途中无敌 |
| 空格 | 跳，用来躲 Boss 砸地的冲击波 |
| E | 走到门前按 E 进门 |
| Tab | 查看这一局拿到的梗卡 |
| Esc | 暂停，解锁鼠标 |

### 5.2 镜头

第三人称，镜头在奶龙身后上方：距离 7 米，高 3.5 米，往下看 20°，视角 60°。准星在屏幕中间偏上，口罩朝准星对准的点飞。画面质感参考第 12.2 节的参考图 4。

### 5.3 奶龙的数值

| 项 | 起始值 |
| --- | --- |
| 生命 | 100 |
| 移速 | 6 米/秒 |
| 冲刺 | 0.2 秒冲出 7 米，无敌 0.25 秒，冷却 1.2 秒 |
| 被打中以后 | 无敌 0.6 秒，身上闪一下。所以敌人一直贴着奶龙，伤害最多每 0.6 秒结算一次 |
| 回血 | 只有清完区域、梗卡和奖励能回血 |

### 5.4 三种攻击

| 攻击 | 起始数值 | 效果 |
| --- | --- | --- |
| 口罩（左键） | 每秒 4 个，飞行速度 22 米/秒，射程 25 米，伤害 10 | 打中敌人造成伤害。打中灰色路人，就给他戴上口罩、把他唤醒，不造成伤害。准星 10° 以内有敌人时，口罩会轻微追踪 |
| N95（右键蓄力） | 伤害 60，最多穿过 3 个敌人，冷却 6 秒 | 用来打大敌人和打掉 Boss 的防御。穿过的灰色路人也会被唤醒 |
| 奶-蛙之波（Q） | 大招条满了才能放 | 镜头猛推到奶龙的眼睛，眼里冒出金色电光，慢放 0.5 秒，奶龙喊出招式名，一圈冲击波扫过整个区域，全屏震荡。效果：所有普通敌人直接被包住；精英受到 300 伤害；Boss 受到最大生命 15% 的伤害，不受 Boss 身上刺的减伤影响；区域里的灰色路人全部被唤醒 |

大招条靠打败敌人和唤醒路人积攒：小病毒 +0.5%，中病毒和喷嚏病毒 +1.5%，大病毒 +5%，精英 +10%，唤醒一个路人 +2%。

大招名「奶-蛙之波」由团队起，来历待团队补充，实现时照原样使用。大招的特效全部自己做，不使用别的作品的画面。

### 5.5 打败敌人：包住，飘上天

- 敌人的生命归零时不会死，而是被一个口罩从四面合拢包住，变成一个口罩包：白色的小包，两根耳挂像翅膀一样扑腾，晃晃悠悠地飘上天。
- 口罩包会一直挂在天上，越积越多。天上的口罩包就是这一局的战绩，一眼就能看出这局打了多少。
- 被包住的大病毒还会在里面拱，包一鼓一鼓的。

### 5.6 灰色路人和彩色路人

- 每个区域有 8 到 15 个灰色路人。他们不是敌人，只会慢慢走或者发呆。
- 用口罩打中一个灰色路人，他戴上口罩，颜色从脚底往上恢复，喊一句这一章的梗台词【待定】，变成彩色路人。
- 彩色路人跟在奶龙附近，每 1.5 秒朝 8 米内的敌人扔一个口罩，伤害 4。他们会一直跟到这一章结束。
- 最多 16 个彩色路人跟着奶龙。超过 16 个时，最早唤醒的那个留在原地欢呼，不再跟随和攻击，但唤醒照样算数（经验、大招条和计分都照算）。
- 每个彩色路人有 3 点“精神”，显示成头顶的 3 个小点。被小病毒、中病毒、喷嚏病毒碰到，或者被飞沫打中，扣 1 点，扣过以后 1 秒内不再扣；被大病毒碰到直接扣光。精神扣光，他就变回灰色，口罩掉在地上，需要重新唤醒。重新唤醒后精神回满。
- 所以玩家要在“清怪”和“护着队友”之间做选择。

### 5.7 连击

2 秒内接连打败敌人会累计连击数，显示在屏幕中间。到 10、25、50、100 时，连击数换颜色，并响一声音效。

### 5.8 地面染色【暂定】（MVP 里放在“有时间再做”，见第 15.2 节）

- 地面有一张颜色图：彩色路人走过的地方变成彩色，大病毒爬过的地方变回灰色。
- 清完一个区域，整个区域染回彩色。
- “变彩”是恢复饱和度，不是把画面调亮。

### 5.9 死亡

生命归零，这一局结束：画面定格、变灰，弹出人生总结（第 10.3 节）。按“人生重开”开始新的一局。

## 6. 梗卡

### 6.1 规则

- 每次三选一的 3 张卡互不相同。
- 稀有度：普通（出现概率 60%）、稀有（30%）、传说（10%）。卡面颜色分别是白、蓝、金。某个稀有度已经没有可抽的卡时，换成低一档的卡。
- 叠加：同一张卡拿第 2 次叠到 2 层，第 3 次叠到 3 层。叠满 3 层的卡不再出现。默认的叠层规则：
  - 伤害、范围、持续时间、回复量、百分比加成：2 层是 1 层数值的 1.5 倍，3 层是 2 倍。例如“伤害 +50%”叠到 2 层是 +75%，3 层是 +100%。
  - 倍率：只放大高出 1 的那部分。例如“伤害 ×2.5”叠到 2 层是 ×3.25，3 层是 ×4。
  - 概率：同上，2 层是 1.5 倍，3 层是 2 倍。例如 10% 叠到 2 层是 15%。
  - 一次扔出的口罩数量、召唤物的数量：每层 +1，伤害不变。
  - 间隔、冷却和负面效果：不随叠层变化。
  - `cards.json` 里单独写了叠层效果的，以数据为准。
- 卡池 = 通用卡池 + 这一章的年代卡池。年代卡池里是那个年代的梗。
- 每张卡都写一句“出处”，告诉不熟悉这个梗的人它是什么。
- 每张卡第一次生效时，要有看得见的画面和听得见的声音：放一句这个梗的台词或音效，头顶弹出梗的名字。

### 6.2 卡的种类

| 类 | 改的是什么 | 门上的图标 |
| --- | --- | --- |
| 口罩改造 | 主攻击的数量、射速、弹道、附加效果 | 攻击 |
| N95 改造 | 技能 | 攻击 |
| 大招改造 | 奶-蛙之波 | 攻击 |
| 被动 | 生命、移速、回血、冲刺等 | 防御 |
| 召唤 | 叫出跟着打的帮手，或者强化彩色路人 | 召唤 |

### 6.3 合体

- 两张前置卡都拿到以后（任意层数），之后每次三选一有 50% 的概率把其中一张换成它们的合体卡。
- 合体卡比两张前置卡加起来更强，样子也会变。
- 拿了合体卡，两张前置卡仍然算在已拿的卡里，层数和其他效果照样有效。合体卡可以替换前置卡的部分表现，例如把两台工程车换成一台机甲，这时前置卡的加成转到新的东西身上（见第 6.5 节）。
- 每张合体卡一局只能拿一次。

## 7. 敌人和 Boss（2020 年春天）

### 7.1 样子

所有病毒都做成圆滚滚的卡通造型，像搪胶玩具：紫灰色，头上一圈小刺，大眼睛，有点蠢。不要像显微镜下的真实病毒。

### 7.2 敌人

移动规则：表里没有另外说明的话，敌人追离自己最近的奶龙或彩色路人。喷嚏病毒停在离奶龙 8 到 12 米的地方打喷嚏。

| 敌人 | 样子 | 生命 | 移速（米/秒） | 攻击 | 特点 |
| --- | --- | --- | --- | --- | --- |
| 小病毒 | 拳头大，一蹦一蹦 | 10 | 4.5 | 碰到奶龙造成 5 伤害 | 成群出现，是割草的主要对象 |
| 中病毒 | 半人高 | 40 | 3 | 碰到造成 10 | 被打败时有 50% 概率分裂成 2 个小病毒 |
| 大病毒 | 两人高 | 150 | 2 | 碰到造成 20，并把奶龙撞开 | 普通口罩打它只有一半伤害；碰到彩色路人直接扣光他的精神（第 5.6 节）；做了地面染色的话，爬过的地面变灰 |
| 喷嚏病毒 | 圆鼓鼓 | 30 | 2.5 | 每 2.5 秒先鼓起来 0.6 秒，再打一个大喷嚏，朝奶龙喷出 3 颗飞沫（10 米/秒，每颗 8 伤害） | 远程敌人，逼玩家走位 |
| 精英：偏方怪 | 头上顶着白酒瓶、醋壶和板蓝根的谣言怪 | 400 | 2 | 每 5 秒吐出一个谣言气泡，上面写着偏方，例如“喝白酒能杀病毒” | 气泡飘向灰色路人，碰到谁，谁就跑去“抢购”，8 秒内不能被唤醒。一个口罩就能打破气泡。偏方怪周围 8 米内的病毒移速 +30% |

### 7.3 刷怪和难度

- 每个区域的波次见第 8.3 节。敌人出现前，地上先冒一团灰雾，0.8 秒后敌人才出来。
- 第 n 个区域的敌人生命 ×（1 + 0.25 ×（n − 1））。Boss 不受这个加成影响。
- 同屏敌人最多 150 个，超过时新刷的敌人排队等待。

### 7.4 Boss【形象待定】

暂定原型是“冠状病毒国王”：头上一圈刺突像王冠，“冠状”这个名字就是这么来的。其他候选：偏方怪升级成 Boss；病毒云（压在城市上空的一片灰云，底下露出一张脸）。不管最后用哪个形象，都按下面三个阶段来打。

场地是山顶的工地，一块半径 25 米的圆形空地。Boss 生命 2500，身高 6 米，碰到奶龙造成 20 伤害。

| 阶段 | 生命 | 移动 | 招式 |
| --- | --- | --- | --- |
| 一 | 100% 到 66% | 每秒 2 米，慢慢走向奶龙 | 身上有一圈 6 根大刺，受到的伤害减少 80%。每打中一发 N95 打掉一根刺，6 根全掉了以后受到正常伤害。每 6 秒朝奶龙射出 5 根刺，呈 60° 扇形，飞行速度 12 米/秒，每根 15 伤害，发射前地上先亮 0.8 秒红线。每 10 秒召出 8 个小病毒 |
| 二 | 66% 到 33% | 每秒 2 米 | 进入这一阶段时，没打掉的刺全部脱落，之后不再减伤。每 8 秒跳起来砸向奶龙所在的位置：落点提前 1 秒亮红圈（半径 4 米），砸中 25 伤害；落地后一圈冲击波向外扩散到 12 米，碰到造成 15 伤害，跳起来能躲过冲击波。射刺照旧。第一阶段的召怪停止，改成每 12 秒召出 6 个小病毒，它们只追彩色路人 |
| 三 | 33% 到 0 | 每秒 3 米 | 身体变大到 8 米。招式和第二阶段一样（射刺、砸地、召怪），所有间隔缩短 30%。灰雾从场地边缘向中心收缩，每秒收缩 0.5 米，最多收缩到半径 8 米：奶龙站在灰雾里每秒受到 5 伤害，彩色路人在灰雾里每秒扣 1 点精神。进入这一阶段时，大招条直接充满一次，保证每局都能看到大招 |

不管最后一击是什么攻击，Boss 生命归零时都播放同一段演出：灰雾散开，Boss 被一个巨大的 N95 包住，慢慢飘上天。

### 7.5 通用规则

- 精英、Boss、每一波怪、Boss 换阶段，都用一次性标记触发：同一个事件只能发生一次，不能每帧重复触发。
- 所有攻击都要有预警：红线、红圈、鼓起来，至少提前 0.6 秒。

## 8. 历史章节

### 8.1 一章由什么组成

一章是一段真实的历史：一个年份、一个地方、当年的大事。每章包括：

- 一张 3D 地图，分成 4 到 6 个区域，最后是 Boss 场地。
- 这一章的敌人：来自当年的大事，或者当年日常生活里的烦恼（第 11.4 节）。
- 年代卡池：那个年代的梗。
- 一段回忆版片段。
- 通过以后，2079 年的城市里多出来的东西。

### 8.2 选题标准（团队定的）

梗和历史题材都按这三条挑：

1. 大众都知道。
2. 有遗憾感、沧桑感。
3. 有抽象感。

### 8.3 MVP：2020 年春天

**真实的背景**：2020 年 1 月 23 日晚上，武汉火神山医院开工，2 月 2 日交付，十天建成。工地开了 24 小时直播，上千万网友在线“云监工”。

**游戏里的这一章**

- 奶龙的身份是医生，穿白色防护服。
- 地图是一片灰色的城区，旁边有一座小山，山上是医院工地。从每个区域都能看到山上的工地。
- 屏幕上方有一本日历，每清完一个区域翻两天，打完 Boss 是第 10 天。山上的工地跟着长：第 2 天平整土地，第 4 天打好地基，第 6 天摆上一排排板房，第 8 天立起红十字，第 10 天完工。
- 天气：开局是阴天，每清完一个区域，天亮一点，打完 Boss 是晴天。
- 这一章的医院在游戏里是虚构的未来建筑，不还原真实医院的样子，不出现病人和病床。游戏里是否直接使用“火神山”这个名字【待定】。

**路线**

```
区域 1 小区门口
   ├─ 门 A → 区域 2A 超市
   └─ 门 B → 区域 2B 菜场
            ↓（两条路都接到这里）
         区域 2 打完，再出现两扇门
   ├─ 门 A → 区域 3A 街道
   └─ 门 B → 区域 3B 广场
            ↓
区域 4 山脚工地 → Boss 山顶
```

**区域和刷怪【暂定】**

清怪区域的结束规则见第 4.3 节：第 3 波刷完以后，场上剩下的敌人少于 5 个时结束。

| 区域 | 类型 | 第 1 波 | 第 2 波 | 第 3 波 | 灰色路人 |
| --- | --- | --- | --- | --- | --- |
| 1 小区门口 | 清怪（教学） | 小 ×15 | 小 ×20 | 小 ×15、中 ×5 | 10 |
| 2A 超市 | 精英 | 小 ×20 | 偏方怪、小 ×20 | 无 | 12 |
| 2B 菜场 | 清怪 | 小 ×30 | 小 ×40 | 小 ×30、中 ×10 | 15 |
| 3A 街道 | 清怪 | 小 ×20、喷嚏 ×4 | 中 ×10、喷嚏 ×6 | 小 ×30、喷嚏 ×8 | 12 |
| 3B 广场 | 清怪 | 中 ×10 | 大 ×2、小 ×30 | 大 ×4、中 ×10 | 15 |
| 4 山脚工地 | 守护 | 60 秒里每 3 秒从四周刷一批：小 ×6，从第 15 秒起每批多 1 个中病毒。病毒优先去打挖掘机 | | | 8（工人） |
| Boss 山顶 | Boss | 第 7.4 节 | | | 无 |

区域 1 的教学按顺序出提示：移动和扔口罩 → 唤醒一个路人 → 冲刺躲开一群小病毒 → 用 N95 打一个中病毒。

区域 4 的守护：场上有 3 台挖掘机，每台生命 200。同一个敌人碰到挖掘机，每秒最多结算一次伤害。60 秒结束时，完好的挖掘机（生命大于 0 的）越多，奖励越好：3 台完好，这次三选一里必有 1 张传说；2 台完好，必有 1 张稀有；1 台或 0 台，没有保底，按正常的稀有度概率抽。挖掘机全坏了也能继续往下打。

**打完 Boss 以后**

1. 回忆片段（约 15 秒）：声音停下，梗字、界面和特效全部消失，天黑下来，工地亮着暖黄色的灯。满天的口罩包一个个亮起来，变成孔明灯。玩家只能慢慢走。最后浮出一行字【待定，团队写】。
2. 回到未来（约 10 秒）：镜头穿过孔明灯一直往上升，天变成 2079 年的晚霞，山上的板房一层层长成未来医院（参考图 1、2），山下的城市变成彩色。
3. 人生总结（第 10.3 节）。

### 8.4 完整版的章节【待定，题材由团队挑】

完整版会有很多章，覆盖不同的年代、地方和国家，每章都按第 8.1 节的格式写。在地球上，每一章是一个点：一个地点加一个年份。

## 10. 局外成长

### 10.1 体验舱大厅（2079 年）

- 完整版：开始新的一局、选人生卡、用记忆碎片解锁内容、看图鉴。每通过一章，大厅窗外的 2079 年城市就多一处被点亮的地方，例如通过 2020 年这一章以后，远处的山上多出一座未来医院。
- MVP：只有标题画面。一间灰色的大厅，一排排体验舱里躺着人，AI 客服的声音说：“欢迎使用人生体验服务。今日推荐：2020 年的春天。”点击“开始”进入。

### 10.2 记忆碎片

- 每局结束时获得：每清完一个区域 10 个，打败 Boss 50 个，每唤醒一个路人 1 个。
- 完整版的用途：解锁新的人生卡、新的章节、放进卡池的新梗卡，以及体验舱升级（例如开局多一次三选一）。
- MVP：只在人生总结里显示数量，不能使用【暂定】。

### 10.3 人生总结

死亡或通关时显示，格式【暂定】：

```
【人生总结】
2020 年的春天，你是一名医生。
你坚持到了第 6 天。            （通关时写：医院在第 10 天建成了。）
送走病毒 312 只，唤醒路人 46 个，最长连击 87。
这一生的梗：云监工、躺着拯救世界、额温枪……
评价：人上人
获得记忆碎片：76               （清完 3 个区域 30 + 唤醒 46 个路人 46）
              [ 人生重开 ]
```

- 评价分五档，从高到低：夯、顶级、人上人、NPC、拉完了。这是 2025 年流行的排名梗“从夯到拉”：把东西从最好到最差排成五档，“夯”是最高一档的夸法，“NPC”表示平平无奇、没有存在感（NPC 原指游戏里的路人角色），“拉完了”是最差的一档。
- 总分【暂定】：包住小病毒 10 分，中病毒和喷嚏病毒 30 分，大病毒 80 分，精英 300 分，Boss 1000 分；唤醒一个路人 5 分；最长连击每 1 次加 10 分；每撑过一天加 100 分；通关加 2000 分。五档的分数线试玩后再定。

### 10.4 图鉴

拿到过的梗卡、遇到过的敌人、通过的章节都会收进图鉴，每条附出处说明。图鉴也是给不熟悉这些梗和历史的玩家看的科普。MVP 可以后做。

## 11. 完整版的其他系统【待定】

本节是团队的设想。具体细节都可以改，题材由团队挑。

### 11.1 人生卡（投胎）

开局抽 3 张人生卡，选 1 张。一张人生卡包括：

| 内容 | 影响什么 |
| --- | --- |
| 出生年份（例如 1950 到 2015 年） | 一局里会经过哪些历史章节，以及经过时奶龙几岁（第 11.2 节） |
| 出生地（城市） | 一个“家乡味道”被动，来自当地的饮食；以及会出现哪些地方的章节、梗和方言台词 |
| 家庭（爸妈是什么样的人） | 开局多带哪张卡；爸妈在这一局里怎么出现（第 11.3 节） |
| 职业（成年以后才有） | 成年以后的章节里主攻击长什么样，例如医生扔口罩、老师扔粉笔、程序员敲键盘打出代码弹幕 |

“家乡味道”的例子：出生在江西（爱吃辣），开局就能喷火，每 10 秒朝前方喷一次；出生在上海（菜偏甜），每打败 50 个敌人回 10 点生命。每个地方的加成都必须是正面的，人生卡的稀有度不能按出生地分高低。

### 11.2 年龄和历史

- 一局按人生阶段排章：童年（6 到 12 岁）、学生（13 到 18 岁）、青年（19 到 30 岁）、中年（31 到 55 岁）、老年（56 岁以上）。
- 每一章写明它适合哪些年龄，以及各个年龄在这一章里的身份。以 2020 年春天为例：6 到 12 岁是上网课的小学生，18 岁是高考推迟的考生，成年人可以是医生（MVP 只做医生）。
- 到了某个人生阶段，地球上会亮起 2 到 3 个可选的章节：它们的年份都落在“出生年份 + 这个阶段的年龄范围”之内。
- 于是不同年龄的人遇到同一件大事，经历的是不同的版本；同样的出生年份，选不同的路线，也会过上不同的一生。

### 11.3 人际关系

- 爸妈、老师、同学、亲戚、同事会出现在各章里，可以是队友、精英敌人，也可以是事件。
- 他们的口头禅可以变成敌人，例如“别人家的孩子”（家长拿来和自己孩子比较的、什么都比你强的别家孩子），也可以变成加成。
- 事件节点：一段对话加一个选择，会影响后面的章节和最后的人生总结。

### 11.4 把比喻当真（设计敌人和场景的规则）

中文里形容日子辛苦的话，在体验舱里会直接变成实物。这些话人人听过，每个人生阶段都有，可以一直套下去：

| 那句话 | 在游戏里 |
| --- | --- |
| 作业堆成山 | 一座真的作业山，要爬上去 |
| 压力山大（压力像山一样大，谐音“亚历山大”） | Boss 名叫“亚历山大”，背上压着一座山 |
| 千军万马过独木桥（形容高考竞争） | 几千个奶龙挤一根独木桥 |
| 题海战术 | 在卷子堆成的海里游泳 |
| 老板画饼（来自“画饼充饥”，指老板许下兑现不了的承诺） | 老板从天上扔下一张张大饼 |
| 甩锅（把责任推给别人） | 同事甩过来一口锅，接住再甩回去，就是弹反 |
| 摸鱼（上班偷懒） | 工位底下摸到一条真鱼，吃了回血 |
| 考不上大学就去搬砖（很多家长常说的话） | 后面的章节里真的要搬砖 |

### 11.5 例子：学生时代的一章

团队的设想：学生打作业怪、默写怪、背书怪，甚至可以具体到打哪一篇课文。

- 作业怪：一沓沓作业纸成群扑过来。
- 默写怪：字一个个飞过来，要按顺序打掉。
- 背书怪：一边念课文，一边让奶龙变慢。
- 课文 Boss：一篇指定的课文，招式就是课文里的句子。语文课本里常见的要求“背诵全文”是学生之间的老梗，可以当它的大招。具体用哪篇课文【待定】。

### 11.6 地球选图

- 每打完一章，回到太空，开着星际战机在地球上选下一章。
- 地球上的点包括不同国家的历史，结合当地的热梗、热图和热歌【待定】。

- 被包住的大病毒还在里面拱。
- 喷嚏病毒打喷嚏前鼓成一个球。
- 彩色路人被唤醒那一下，像果冻一样压扁再弹回来。

Tripo 模型的处理流程：参考图先抠干净背景 → 生成 → 减面 → 绑骨 → 套用预设动作 → 导出 GLB → 用 `gltf-transform optimize in.glb out.glb --compress draco --texture-compress webp` 压缩 → 在 `assets.json` 里登记。

规格：1 个单位等于 1 米，Y 轴朝上，正面朝 +Z，原点在脚底中心。奶龙身高 1.2 米，路人 1.75 米。单张贴图不超过 1024×1024。

## 13. 声音

- 音乐：每章一首，按战斗的激烈程度分几层，越激烈叠的层越多；Boss 战单独一首；回忆片段时音乐全部停掉。音乐自己做，或者用可以商用的授权音乐。
- 梗台词：团队自己配音，不用原片录音。每张梗卡第一次生效时放它的台词。同一时刻最多 2 条台词，台词响的时候音乐压低 4 dB。
- 音效：扔口罩的“嗖”、包住时的“唔—噗”、口罩包飘走的气球声、喷嚏、冲击波、工程车、路人欢呼。用 CC0 音效库，或者用代码合成。
- 浏览器只有在用户点击以后才允许出声，所以标题画面的“开始”按钮同时负责打开声音。

## 14. 技术方案

### 14.1 技术栈

- Three.js r187（WebGLRenderer，WebGL2）。
- 用 esbuild 把 `src/` 打包成一个 IIFE 格式的 `app.js`，页面用普通的 `<script src="./app.js">` 引入。打包结果也提交到仓库，放到任何静态托管上都能直接打开。
- 不用物理引擎：碰撞用球体检测加空间哈希，撞开、抛物线、弹跳都用简单的运动学代码。
- 玩法里所有随机都用带种子的随机数生成器（例如 mulberry32），不用 `Math.random`。同一个种子、玩家每次做同样的选择（进同一扇门、选同一张卡）时，必须得到完全一样的一局：一样的门图标、一样的三选一、一样的刷怪位置。做法：门、抽卡、刷怪各用一条独立的随机数序列，互不影响。第 n 次三选一固定使用抽卡序列里的第 n 组随机数，和这次三选一发生在第几秒无关；第 n 个敌人的出生位置固定使用刷怪序列里的第 n 组随机数。伤害没有随机浮动。

```json
}
```

### 14.5 关键做法

- 状态机：每个画面（标题、人生卡、开场、区域、三选一、Boss、回忆、回到未来、人生总结）是一个状态，状态之间只通过 `state.js` 切换。
- 暂停：三选一、Tab 看卡和 Esc 时，游戏时钟停止，敌人和投射物都不动。
- 刷怪：按 `chapters.json` 的波次刷。前一波的敌人（包括分裂出来的）打掉 80% 时刷下一波；第 3 波刷完以后，场上少于 5 个敌人时区域结束（第 4.3 节）。
- 渲染：每种小敌人用一个实例网格，一次画完；灰色路人也一样。
- 包住的动画：敌人缩小，口罩从四面合拢（0.3 秒），然后换成口罩包往上飘，速度 2 米/秒，左右轻轻摆。口罩包用一个实例网格，最多 300 个，超过时把最早的几个合并成更大的一团。
- 灰色和彩色：在材质的 `onBeforeCompile` 里加一个饱和度参数，在 15% 和 100% 之间插值。路人和敌人按实例设置，场景按区域设置；做了地面染色的话，地面按一张 256×256 的颜色图采样。
- 大招：慢放时只放慢动画和物理（时间缩放 0.2，持续 0.5 秒）。冲击波在后期里做：以奶龙在屏幕上的位置为圆心，一圈画面扭曲往外扩，同时加色差和震屏。
- 自动追踪：口罩飞行时，每帧朝准星 10° 内最近的敌人转一点方向，每秒最多转 60°。

### 14.6 性能预算

| 项 | 上限 |
| --- | --- |
| 帧率 | 演示电脑上 1920×1080 平均不低于 55 帧；集成显卡的笔记本用中档画质也要达到 |
| 同屏敌人 | 150 |
| 同时飞行的口罩 | 200（对象池） |
| 天上的口罩包 | 300 |
| 彩色路人 | 16 |
| 实时点光源 | 4 |
| 第一次打开要下载的文件 | 20 MB |

### 14.7 已知的坑

- 同一个事件只能触发一次。不加一次性标记的话，事件会每帧触发，例如一下子生成几十个 Boss。
- 泛光的阈值、强度和曝光固定不变，不要随游戏进度调高，否则画面会越玩越白。“变彩”是提高饱和度。
- 泛光之前要先把坏像素（NaN、无穷大）清零，否则在真显卡上会出现整块闪黑。
- 提交前核对每个素材文件有没有真的被加载和使用，没用上的删掉。
- 截图检查除了默认镜头，还要看：镜头拉到最高往下看、贴着背光面、走到地图边上回头看。
- 无头浏览器用软件渲染，截图和真显卡上的效果不一样。每一版都要在演示用的电脑上实际看一遍。

### 14.8 调试参数

| 网址参数 | 作用 |
| --- | --- |
| `?seed=123` | 固定随机种子 |
| `?demo=1` | 演示短局：区域 1、区域 4、Boss |
| `?god=1` | 奶龙不会死，演示时防意外 |
| `?zone=3a` | 直接从某个区域开始 |
| `?boss=1` | 直接打 Boss |
| `?cards=cloud_supervisor,oh_mud_chan` | 开局就带上这些梗卡 |
| `?q=low`、`?q=mid`、`?q=high` | 画质档位 |
| `?mute=1` | 静音 |
| `?debug` | 显示帧率、绘制次数、敌人数量、当前状态 |

### 14.9 交付

- 一个静态文件夹：用 `node serve.mjs` 或 `python3 -m http.server` 起本地服务器就能玩，断网也能跑。不能直接双击 `index.html` 打开，浏览器会拦住本地的贴图和模型。
- 推到公开的 GitHub 仓库后，可以用 `https://htmlpreview.github.io/?` 加上文件在 GitHub 上的地址直接打开。
- 演示前录一段 1080p、每秒 60 帧的备份视频，演示电脑和 U 盘各存一份。现场出问题就放视频。

## 15. MVP 范围和验收

### 15.0 开发顺序

| 步 | 做什么 | 做完的标准 |
| --- | --- | --- |
| 1 方块原型 | 用方块当奶龙、病毒和路人：移动、冲刺、扔口罩、包住、口罩包飘上天、唤醒路人、经验和三选一（先做 4 张卡）、死亡和人生重开 | 找 3 个人各玩 1 分钟，有人主动要求再来一局。不好玩就先调规则，不做美术 |
| 2 一章能打通 | 6 个区域和路线、围挡和门、四种病毒、偏方怪、Boss 三个阶段（先用方块）、日历、回忆片段和人生总结（先用简单画面） | 能从区域 1 打到 Boss 通关，也能中途死亡重开 |
| 3 内容做全 | 第 6.4、6.5 节的全部梗卡、叠加、合体、HUD、调试参数 | 第 15.3 节里和玩法有关的项都能打勾 |
| 4 好看好听 | 换上模型、天空、开场飞行、未来医院、音乐、音效、台词 | 投影上看着好看；性能达标 |
| 5 有时间再做 | 第 15.2 节 | 无 |

时间不够时，按这个顺序砍：先把开场飞行换成一张静态图；再去掉超市和广场，路线只剩菜场和街道，偏方怪和大病毒也就不用做了；再去掉合体卡；最后把 Boss 的第二阶段并进第三阶段。第 1 步的内容不能砍。

### 15.1 必须有

- 标题画面（体验舱）、固定的人生卡、飞向地球的开场（可以跳过）。
- 奶龙：移动、冲刺、跳、被打中、死亡。
- 三种攻击；包住和口罩包飘上天。
- 灰色路人和彩色路人。
- 四种病毒、偏方怪、三个阶段的 Boss。
- 2020 年春天的 6 个区域（两次二选一的路线）、施工围挡和门。
- 经验、升级三选一、区域奖励、叠加、合体。
- 第 6.4 和 6.5 节的梗卡：至少 12 张梗卡（不算合体卡）和 2 张合体卡能用。
- 日历、工地进度、天气变化。
- 回忆片段、回到未来、人生总结、人生重开。
- 界面：HUD、三选一、暂停、Tab 看卡。
- 声音：音乐、音效；台词可以先用占位音效。
- 第 14.8 节的调试参数和画质档位。

### 15.2 有时间再做

- 地面染色（第 5.8 节）。
- 连击时喊梗台词、弹出 Blender 做的立体字。
- 图鉴。
- 记忆碎片的用途。
- 让台下观众扫码发弹幕，弹幕越多，工程车干得越快（需要服务器；现场网络不稳就用预先录好的弹幕）。

### 15.3 验收清单

- [ ] 从标题画面到落进城市，控制台没有报错；开场能跳过。
- [ ] 一局能从区域 1 打到 Boss 并通关；也能中途死亡、人生重开。
- [ ] 同一个种子打两次，每次进同样的门、选同样的卡，门图标、三选一和刷怪位置完全一样。
- [ ] 至少 12 张梗卡和 2 张合体卡能抽到、能生效，每张生效时有画面和声音。
- [ ] 第一次玩的人不看说明，30 秒内学会扔口罩和唤醒路人。
- [ ] Boss 的三个阶段都能触发，每个阶段只触发一次；在 30 帧和 144 帧的显示器上各打一遍，Boss 始终只有一个。
- [ ] 同屏 150 个敌人时，演示电脑 1920×1080 平均不低于 55 帧；放大招那一下单帧不超过 33 毫秒。
- [ ] 画面任何时刻过曝的纯白像素不超过 10%。
- [ ] 第一次打开下载不超过 20 MB；断网也能玩。
- [ ] `?demo=1` 的短局 3 到 4 分钟能打完；`?god=1` 时奶龙不会死。
- [ ] 投影上最后一排能看清梗卡的字。
- [ ] 公开发布的版本没有原片录音，没有品牌的官方 logo；奶龙已经获得授权，或者换成了团队的原创角色。

## 16. 内容红线和版权

**疫情题材**

- 只用医护的付出、普通人之间的互助，以及那几个月里荒诞好笑的日常。
- 不出现死亡、病床和病人；不用真人的名字、照片和新闻画面；不涉及 2022 年的封控和具体政策。
- 病毒一律做成卡通怪兽。灰色只表示“没精神”，不表示生病。
- 结尾落在希望上。

**其他题材**

- 不做造成大量伤亡的灾难，例如地震。
- 地区：每个地方的人生卡加成都是正面的，稀有度不能按出生地分高低。
- 真人：不用真人的形象、照片和声音。来自影视剧的梗只用台词，台词由团队重新配音。
- 品牌：不出现官方 logo 和字标，和品牌有关的梗换个说法。
- 音乐：自己做，或者用可以商用的授权音乐，不用原曲。

**奶龙**

奶龙有著作权方：它和樟宜机场等品牌做过合作，著作权方也公开澄清过未经授权的使用。公开发布、发视频或者参加有奖金的比赛之前，要先获得授权，或者把主角换成团队自己的原创角色，“望子成龙”的梗照样能用。在这之前，不使用奶龙的官方图片和配音。

**火神山**

火神山是真实医院的名字。游戏里的建筑是虚构的未来建筑。游戏里是否直接使用这个名字【待定】。
